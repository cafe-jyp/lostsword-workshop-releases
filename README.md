# 로스트소드 공방

로스트소드의 계정 육성 기록, 팀 편성 및 전투 시뮬레이션을 위한 비공식 팬 제작 앱입니다.
광고와 유료 기능 없이 무료로 제공합니다.

이 저장소는 Android APK와 변경 내역을 배포하기 위한 공간입니다. 앱 소스 코드는 포함하지 않습니다.

## 설치

1. 이 저장소의 **Releases**에서 원하는 버전을 엽니다.
2. **Assets**에서 `.apk` 파일을 휴대전화에 다운로드합니다.
3. 파일을 열고 Android의 안내에 따라 설치합니다.

`Source code (zip)`과 `Source code (tar.gz)`는 이 안내 저장소의 압축 파일이며 앱 설치 파일이 아닙니다.
설치 출처가 이 저장소인지 확인하고, 필요할 때만 해당 설치 앱의 권한을 허용해주세요.

## 업데이트

새 Releases의 APK를 내려받아 설치합니다. 자동 업데이트 기능은 제공하지 않습니다.
이 배포 채널의 같은 서명으로 만든 APK끼리는 업데이트할 수 있습니다.

개발용·테스트용 APK는 배포용 APK와 서명이 달라 덮어쓰기 설치가 불가능합니다.
기존 앱 삭제 전에 계정 동기화 및 필요한 기록 백업을 확인하세요. 앱 삭제 시 기기에만 저장된 데이터는 삭제됩니다.
Google Play 버전으로의 덮어쓰기 전환은 추후 Play 앱 서명 설정에 따라 달라집니다.
